# Taksim

Taksim is a local-first control plane for AI coding agents, built around a sufficiency ledger. It reads the local history and hooks of coding agents (Claude Code, Codex, GitHub Copilot CLI, Devin, Devin Desktop, OpenCode, Kilo Code, Pi and Oh My Pi, Agent Workstation), prices every session, and grades finished turns with an LLM judge to show when a cheaper model would have been enough. It stores metadata only: no prompts, responses, code or credentials. Local repository folders stay in your local database only, to attribute cost, and never appear in exports.

Install (one line, PowerShell): {{installCommand}}
The installer downloads the latest release over HTTPS, verifies it against SHA256SUMS.txt, installs into %LOCALAPPDATA%\Taksim, adds it to the user PATH and runs `taksim setup`. Then `taksim dashboard` opens the local results dashboard. `taksim update` checks for a newer release; `taksim update --apply` installs it (it first checks the installer against SHA256SUMS.txt and refuses on a mismatch or a missing entry; a signed installer must come from a publisher pinned in the binary). `taksim doctor` checks health and coverage.

Client boundary (Observe = history import and reports; Judge = LLM judge grades finished turns; Route = optional live model choice):
- Claude Code on a Claude plan (Free, Pro, Max, Team, Enterprise): history import, hooks, status line, judging, reports. Observed by default. Opt-in: `taksim routing subscription on` (off by default) routes `taksim claude` on a Pro, Max or Team login through the local gateway for Claude-only model switching; the login stays the credential and is never read, copied or logged.
- Claude Code on an Anthropic API key: all of the above, plus optional live routing through the local gateway in sessions launched with `taksim claude`.
- Codex CLI on a ChatGPT plan: history import from `CODEX_HOME` sessions, judging (history judging and an in-session Stop hook), reports. Observe-only in the current release.
- Codex CLI on an OpenAI API key: history import, judging, reports. Observed; not routed. Taksim routes only between Claude models.
- GitHub Copilot CLI: usage import from the local Copilot CLI session store, reports. Not judged; no request-time routing.
- Devin CLI: history import and reports. Not judged; no routing.
- Devin Desktop (formerly Windsurf): history import and judging. Observe-only; never routed.
- OpenCode and Kilo Code: history import and judging (Claude-tier models). No routing.
- Pi and Oh My Pi: history import and judging (Claude-tier models). No routing.
- Agent Workstation: usage import from its local usage ledger (`aw-usage-YYYY-MM.jsonl`), reports; approvals are kept as weak quality evidence. Not judged; no routing.

A verdict counts toward the "could have saved" figure only when two judges agree and at least one is a strong judge. The figure is an estimate with its sample size shown, never a guarantee.

Cache guard (`taksim cache-guard enable`): informational Claude Code hooks that say when a large session resumes after its prompt cache expired, with the tokens and cost to re-cache, and, through the context guard, once when a session passes a size threshold (default 200,000 tokens, `--context-threshold`), with the per-turn cost of carrying it. Never blocks, never sends a request. `taksim cache-guard status` shows the threshold. Cache writes are priced at the lifetime each one recorded (5 minutes or 1 hour), fast mode and web search included; `taksim insights cache` shows the TTL mix and which pauses cost a re-cache.

Subscription quota (`taksim insights quota`): 5-hour and weekly limit usage for Claude Pro/Max and ChatGPT-signed-in Codex, from the readings the clients already report (limit hits, peaks, pace, and usage by repository, model and session). Never reads subscription credentials and never calls a vendor usage endpoint. The status line shows a quota segment once a window passes 75%. Spend anomalies (`taksim insights anomalies`): compares recent spend with the 28 days before and lists spend spikes, runaway sessions, Opus/fast-mode share shifts, subscription-to-API-key switches and new unpriced models, each with the reason and a suggested action; silent until the baseline has enough history.

Routing on your own API key (pay-per-token only): `taksim routing recommend` suggests a default model tier per repo, task class and client from consensus verdicts, with sample size, confidence and the saving on the judged turns; thin or contrary evidence keeps the current model, and it only advises. `taksim routing auto on` (off by default) applies a recommended downgrade only when a fresh context starts in a `taksim claude` session on an Anthropic API key; running conversations are never switched, and pins, budgets and native `/model` choices win. A downgraded turn with failure signals (tool, test or build failures, retries or corrections, upstream errors) escalates back to the requested model for that phase, and a downgraded call that fails before any response byte is retried once on the requested model. `taksim diagnostics downgrades` lists downgrades and escalations. `taksim mode economy|balanced|quality` is one switch over these settings (`taksim mode` shows the mode in force): `balanced` is the defaults, `economy` turns `routing.auto` on and runs ordinary requests on Sonnet at low effort instead of medium, `quality` keeps it off and runs them on Opus at medium effort without the Haiku tier; Claude models only, limited to those the organisation's managed model policy allows, and pins, an explicit effort, escalation and required safety are unchanged. Claude Code's `/advisor` is forwarded unchanged and never paired with an executor the API would refuse; advisor tokens are recorded and priced at the advisor model's rates (`taksim report task-cost`). Claude subscription routing is a separate opt-in (see below); ChatGPT plans are observed only and never routed.

Usage and cost: API-key usage is shown in billed dollars; subscription usage is shown as API-equivalent list-price dollars, labelled as quota, not billed. `taksim dashboard` is a local, read-only dashboard on 127.0.0.1. Reports are on demand: `taksim report weekly`, `taksim digest`, `taksim report summary`. Budgets (`taksim budget set`) warn by default and never block a request; the opt-in `taksim budget enforce --mode downgrade` (off by default) serves routed Claude requests on Sonnet (or Haiku with `--to haiku`) while a developer or repo budget is at or above its threshold, never blocking or leaving Claude. The digest and budget alerts can be sent to Slack or a webhook you configure with `taksim notify configure`.

Pricing: the Developer plan (the CLI) is free for any individual developer, at home or at work, with no account. Everything that saves money or shows evidence is free: the ledger and history import, the local dashboard and weekly report, spend and subscription quota visibility, judging with two-judge consensus, decision memory and verification evidence, manual routing (`taksim mode economy|balanced|quality`), automatic outcome-learned routing (`taksim routing auto on`), opt-in Claude-only routing on a Claude subscription (`taksim routing subscription on`), budget warnings that never block, and the proof export (`taksim proof export`, in development and not in the current release). Pro is $12 per month (the first 20 customers get 50% off for the first 12 months) and adds automation and enforcement: budget caps that step down to a cheaper Claude model (`taksim budget enforce --mode downgrade`), digest delivery to Slack or a webhook, the HTML executive summary (`taksim report summary --html`), native-router audit details beyond the headline figure (planned, not in the current release) and priority support. Team is $18 per active developer per month with a 5-developer minimum ($90 per month); it is Pro plus the team roll-up (`taksim report team`), team budgets and org policy (planned, not in the current release). Paid plans are not on sale yet: reserving a founding seat or starting a team pilot costs nothing (https://taksim.edgee.tech/contact), and billing opens when checkout is live. The team roll-up is built from exports each developer creates and can inspect before sharing; exports carry repo aliases, never paths.

There is no Taksim account, sign-in or server: install Taksim and use it. Nothing is sent to a Taksim server; none exists.

The ledger and dashboard stay local. Update and pricing checks use external network services. An optional remote judge receives truncated excerpts of the turns it grades; configured Slack/webhook destinations receive aggregate reports and repo aliases. There is no default hosted routing-advice service. Claude Code, Codex, and similar clients independently send prompts and responses to their own provider under that provider's terms.

Subscription traffic is observed by default: when Claude Code runs on a Claude subscription, or Codex on a ChatGPT sign-in, `taksim claude` / `taksim codex` launch the client natively and observe it from local transcripts and hooks. Claude subscription routing is opt-in (`taksim routing subscription on`, off by default). With it on, `taksim claude` on a claude.ai login (Pro, Max, Team) goes through the local gateway; only `ANTHROPIC_BASE_URL` is set, the login stays the credential, the gateway forwards `Authorization` unchanged and never reads, copies or logs it, and usage stays on the subscription (quota, not invoiced). Taksim switches only among Claude catalog models, never third-party models, within the organisation's `availableModels`; `--model` and `/model` switches away from the start model are kept, and it fails open to your original request. The first real request of a session is chosen by task fit (an Opus default can step down one tier when the task fits) and escalates on failure evidence; warm-cache sessions stay sticky. Requests Taksim raises to Opus use plan quota faster; usage is reported as plan quota. EdgeeTech reads Anthropic's terms as allowing a choice among Claude models and forbidding third-party models; this is not an endorsement by Anthropic. Anthropic's Legal and compliance page restricts third-party intermediation of Claude.ai credentials (it names Free, Pro and Max; Team and Enterprise are not clearly addressed), so `routing.subscription` is off by default and you decide whether to turn it on. Codex on a ChatGPT plan stays observe-only; Taksim has not verified that OpenAI's proxy path keeps plan, quota and workspace controls. API-key routing (`x-api-key`) is separate and applies only in sessions launched through Taksim.

Economic modes: subscription plans are included usage and quota (shown as API-equivalent list price, labelled as quota, never as billed dollars); API keys are billed dollars per token; private or local model capacity is not a routing target in the current release.
