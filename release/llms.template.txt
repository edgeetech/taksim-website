# Taksim

Taksim is a local-first sufficiency ledger for AI coding. It reads the local history and hooks of coding agents (Claude Code, Codex, GitHub Copilot CLI, Devin, Devin Desktop, OpenCode, Kilo Code, Pi and Oh My Pi), prices every session, and grades finished turns with an LLM judge to show when a cheaper model would have been enough. It stores metadata only: no prompts, responses, code, paths or credentials.

Install (one line, PowerShell): {{installCommand}}
The installer downloads the latest release over HTTPS, verifies it against SHA256SUMS.txt, installs into %LOCALAPPDATA%\Taksim, adds it to the user PATH and runs `taksim setup`. Then `taksim dashboard` opens the local results dashboard. `taksim update` checks for a newer release; `taksim update --apply` installs it. `taksim doctor` checks health and coverage.

Client boundary (Observe = history import and reports; Judge = LLM judge grades finished turns; Route = optional live model choice):
- Claude Code on a Claude plan (Free, Pro, Max, Team, Enterprise): history import, hooks, status line, judging, reports. Observe-only: no proxy and no model changes.
- Claude Code on an Anthropic API key: all of the above, plus optional live routing through the local gateway in sessions launched with `taksim claude`.
- Codex CLI on a ChatGPT plan: history import from `CODEX_HOME` sessions, judging (history judging and an in-session Stop hook), reports. Observe-only.
- Codex CLI on an OpenAI API key: all of the above, plus optional live routing through the local gateway in sessions launched with `taksim codex`.
- GitHub Copilot CLI: usage import from the local Copilot CLI session store, reports. Not judged; no request-time routing.
- Devin CLI: history import and reports. Not judged; no routing.
- Devin Desktop (formerly Windsurf): history import and judging. Observe-only; never routed.
- OpenCode and Kilo Code: history import and judging (Claude-tier models). No routing.
- Pi and Oh My Pi: history import and judging (Claude-tier models). No routing.

A verdict counts toward the "could have saved" figure only when two judges agree and at least one is a strong judge. The figure is an estimate with its sample size shown, never a guarantee.

Usage and cost: API-key usage is shown in billed dollars; subscription usage is shown as API-equivalent list-price dollars, labelled as quota, not billed. `taksim dashboard` is a local, read-only dashboard on 127.0.0.1. Reports are on demand: `taksim report weekly`, `taksim digest`, `taksim report summary`. Budgets (`taksim budget set`) are warnings only; nothing is blocked. The digest and budget alerts can be sent to Slack or a webhook you configure with `taksim notify configure`.

Pricing: the CLI is free for any individual developer, at home or at work. Team is $8 per active developer per month, $99 per month minimum, 20% off with annual billing. The team roll-up is built from exports each developer creates and can inspect before sharing; exports carry repo aliases, never paths.

Sign-in is optional and off by default: install Taksim and run it with no account. Hosted sign-in only activates when an operator sets `Identity__Enabled=true`, in which case it supports Google/GitHub browser sign-in and stores device credentials in Windows Credential Manager (up to 24 hours, no automatic refresh).

Everything runs locally on 127.0.0.1 by default; nothing leaves the machine unless you opt in to a hosted Taksim feature, a remote judge on your own key (which receives truncated excerpts of the turns it grades), or a Slack/webhook destination you configure (which receives aggregates and repo aliases only). There is no default hosted routing-advice service. This does not describe the native AI client itself: Claude Code, Codex, and similar clients still send prompts and responses to their own provider under that provider's terms, independent of Taksim.

Subscription traffic is observed, never proxied: when Claude Code runs on a Claude subscription (`Authorization: Bearer`), or Codex on a ChatGPT sign-in, `taksim claude` / `taksim codex` launch the client natively and observe it from local transcripts and hooks. There is no opt-in to change this. Model routing applies only to API-key traffic (`x-api-key`), and only in sessions launched through Taksim.
