# Taksim

Taksim is a local-first control plane for AI coding agents, built around a sufficiency ledger. It reads the local history and hooks of coding agents (Claude Code, Codex, GitHub Copilot CLI, Devin, Devin Desktop, OpenCode, Kilo Code, Pi and Oh My Pi, Agent Workstation), prices every session, and grades finished turns with an LLM judge to show when a cheaper model would have been enough. It stores metadata only: no prompts, responses, code, paths or credentials.

The installer downloads the latest release over HTTPS, verifies it against SHA256SUMS.txt, installs into %LOCALAPPDATA%\Taksim, adds it to the user PATH and runs `taksim setup`. Then `taksim dashboard` opens the local results dashboard. `taksim update` checks for a newer release; `taksim update --apply` installs it. `taksim doctor` checks health and coverage.

Client boundary (Observe = history import and reports; Judge = LLM judge grades finished turns; Route = optional live model choice):
- Claude Code on a Claude plan (Free, Pro, Max, Team, Enterprise): history import, hooks, status line, judging, reports. Observe-only in the current release: no proxy and no model changes.
- Claude Code on an Anthropic API key: all of the above, plus optional live routing through the local gateway in sessions launched with `taksim claude`.
- Codex CLI on a ChatGPT plan: history import from `CODEX_HOME` sessions, judging (history judging and an in-session Stop hook), reports. Observe-only in the current release.
- Codex CLI on an OpenAI API key: all of the above, plus optional live routing through the local gateway in sessions launched with `taksim codex`.
- GitHub Copilot CLI: usage import from the local Copilot CLI session store, reports. Not judged; no request-time routing.
- Devin CLI: history import and reports. Not judged; no routing.
- Devin Desktop (formerly Windsurf): history import and judging. Observe-only; never routed.
- OpenCode and Kilo Code: history import and judging (Claude-tier models). No routing.
- Pi and Oh My Pi: history import and judging (Claude-tier models). No routing.
- Agent Workstation: usage import from its local usage ledger (`aw-usage-YYYY-MM.jsonl`), reports; approvals are kept as weak quality evidence. Not judged; no routing.

A verdict counts toward the "could have saved" figure only when two judges agree and at least one is a strong judge. The figure is an estimate with its sample size shown, never a guarantee.

Cache guard (`taksim cache-guard enable`): informational Claude Code hooks that say when a large session resumes after its prompt cache expired, with the tokens and cost to re-cache, and, through the context guard, once when a session passes a size threshold (default 200,000 tokens, `--context-threshold`), with the per-turn cost of carrying it. Never blocks, never sends a request. `taksim cache-guard status` shows the threshold. Cache writes are priced at the lifetime each one recorded (5 minutes or 1 hour), fast mode and web search included; `taksim insights cache` shows the TTL mix and which pauses cost a re-cache.

Subscription quota (`taksim insights quota`): 5-hour and weekly limit usage for Claude Pro/Max and ChatGPT-signed-in Codex, from the readings the clients already report (limit hits, peaks, pace, and usage by repository, model and session). Never reads subscription credentials and never calls a vendor usage endpoint. The status line shows a quota segment once a window passes 75%. Spend anomalies (`taksim insights anomalies`): compares recent spend with the 28 days before and lists spend spikes, runaway sessions, Opus/fast-mode share shifts, subscription-to-API-key switches and new unpriced models, each with the reason and a suggested action; silent until the baseline has enough history.

Routing on your own API key (pay-per-token only): `taksim routing recommend` suggests a default model tier per repo, task class and client from consensus verdicts, with sample size, confidence and the saving on the judged turns; thin or contrary evidence keeps the current model, and it only advises. `taksim routing auto on` (off by default) applies a recommended downgrade only when a fresh context starts in a `taksim claude` session on an Anthropic API key; running conversations are never switched, and pins, budgets and native `/model` choices win. A downgraded turn with failure signals (tool, test or build failures, retries or corrections, upstream errors) escalates back to the requested model for that phase, and a downgraded call that fails before any response byte is retried once on the requested model. `taksim diagnostics downgrades` lists downgrades and escalations. Claude and ChatGPT subscription plans are observed only and never routed.

Usage and cost: API-key usage is shown in billed dollars; subscription usage is shown as API-equivalent list-price dollars, labelled as quota, not billed. `taksim dashboard` is a local, read-only dashboard on 127.0.0.1. Reports are on demand: `taksim report weekly`, `taksim digest`, `taksim report summary`. Budgets (`taksim budget set`) are warnings only; nothing is blocked. The digest and budget alerts can be sent to Slack or a webhook you configure with `taksim notify configure`.

Pricing: the Developer plan (the CLI) is free for any individual developer, at home or at work, with no account. It includes history import, the local dashboard and weekly report, spend and subscription quota visibility, judging with two-judge consensus, decision memory and verification evidence, and optional routing on your own API key. Team is $8 per active developer per month, $99 per month minimum, 20% off with annual billing. The team roll-up is built from exports each developer creates and can inspect before sharing; exports carry repo aliases, never paths.

There is no Taksim account, sign-in or server: install Taksim and use it. Nothing is sent to a Taksim server; none exists.

The ledger and dashboard stay local. Update and pricing checks use external network services. An optional remote judge receives truncated excerpts of the turns it grades; configured Slack/webhook destinations receive aggregate reports and repo aliases. There is no default hosted routing-advice service. Claude Code, Codex, and similar clients independently send prompts and responses to their own provider under that provider's terms.

In the current release, subscription traffic is observed, not proxied: when Claude Code runs on a Claude subscription (`Authorization: Bearer`), or Codex on a ChatGPT sign-in, `taksim claude` / `taksim codex` launch the client natively and observe it from local transcripts and hooks. There is no opt-in to change this. Model routing applies only to API-key traffic (`x-api-key`), and only in sessions launched through Taksim. Why: Anthropic's current Legal and compliance page for Claude Code bars third-party developers from routing Free, Pro or Max credentials on behalf of their users or intermediating Claude.ai credentials, and Taksim has not verified that OpenAI's proxy path for ChatGPT sign-in keeps plan, quota and workspace controls (both reviewed October 2026). Any change ships in a Taksim release first.

Economic modes: subscription plans are included usage and quota (shown as API-equivalent list price, labelled as quota, never as billed dollars); API keys are billed dollars per token; private or local model capacity is not a routing target in the current release.
